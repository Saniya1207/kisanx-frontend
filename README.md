# 🌾 KisanX Frontend

KisanX Frontend is a React Native mobile application that provides a seamless marketplace experience for farmers and customers. The application enables users to browse agricultural products, manage carts and wishlists, place orders, and track deliveries through an intuitive mobile interface.

# 🌾 KisanX — D2C Agricultural Marketplace

> **Built by [Saniya Farooqui](https://www.saniya.me) — Co-Founder & Full-Stack Developer**
> 
> A live Direct-to-Consumer (D2C) agricultural marketplace connecting Indian farmers directly with buyers — eliminating middlemen and ensuring fair pricing for farmers.
