# 🌾 KisanX Frontend

KisanX Frontend is a React Native mobile application that provides a seamless marketplace experience for farmers and customers. The application enables users to browse agricultural products, manage carts and wishlists, place orders, and track deliveries through an intuitive mobile interface.

## Features

- User Authentication
- Customer Dashboard
- Product Browsing
- Shopping Cart
- Wishlist Management
- Checkout Flow
- Order Tracking
- Profile Management
- Reward Points System

## Tech Stack

- React Native
- Expo Router
- TypeScript
- Context API
- AsyncStorage
- Expo SecureStore

## Screens

- Login & Registration
- Dashboard
- Product Details
- Cart
- Wishlist
- Checkout
- Order Tracking
- Profile

## Repository Purpose

This repository contains only the frontend/mobile client of the KisanX application.
